# 18. 常见坑

- 输出只在一次 server update 尝试，未声明稳定的 `MeOutputPort`，网络满后无法由 support ticker 重试。
- 具体机器自行解析 AE key 或先 execute 部分输入；输入必须交给 router 做完整 simulate/execute/rollback。
- 忘记 `addContainerTrackers`，AE 输出模式或 smart-pattern 状态客户端不同步。
- 忘记通过 support 保存/加载 slots，重进世界样板槽或 pending 数据丢失。
- 忘记 `ICraftingProvider.requestUpdate`，样板变化后 AE 终端不刷新。
- `MeMekanismMachine` 稳定 ID、catalog `sourceBlockId` 和生成资源名不一致。
- optional 实现被公共 registry、client 或 JEI 主类静态链接，未安装附属模组时崩溃。
- catalog family、provider requirement 或 client family gate 不完整，导致机器注册或 screen/JEI 缺失。
- `CompatFactoryTierGraph` 中混用不同 namespace/tier 链，安装器升级到错误机器。
- BlockType 的 profile、TransmissionType 或上游 shape 与机器真实能力不一致。
