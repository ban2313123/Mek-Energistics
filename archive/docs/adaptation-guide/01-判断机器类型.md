# 1. 先判断机器类型

新增机器前先确认两个维度：注册 family 与物理 I/O。前者决定 provider/family adapter，后者决定 `MeInputLayout` 和输出端口。

常见 I/O：

- `item -> item`：Enrichment Chamber、Crusher、Energized Smelter；
- `item + chemical -> item`：Metallurgic Infuser、Osmium Compressor、Purification Chamber；
- `item + item -> item`：Combiner、CNC Stamper，通常需要固定 lane；
- `item -> item + item`：Precision Sawmill，需声明副输出；
- `chemical/fluid -> chemical/fluid`：Infuser、Washer、Oxidizer、Separator、Rotary；
- `item + fluid + chemical`：Pressurized Reaction Chamber；
- 非配方工具：Digital Miner、Teleporter、Sorter 等，不加入 AE crafting provider。

判断依据不是 recipe Java 类型，而是上游机器实际允许进入哪些槽/罐、哪些位置可交换、哪些输出端口要回网。具体机器不得根据 Mekanism recipe 类型选择 AE 投料路径。

注册层再选择 `CompatMachineFamily`：普通机器、普通工厂或高级工厂，以及所属 Mekanism/MekMM/MEKE/EMEK/EMEKE provider。provider、route 和 kind 均从 family 派生。
