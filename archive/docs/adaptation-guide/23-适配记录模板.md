# 23. 适配记录模板

每新增一个机器族，在 PR 或提交说明中记录：

```text
provider / CompatMachineFamily:
catalog machines:
source block ids:
machine kind / factory tiers / machine type:
requirements / optional class probes:
server provider + family adapter:
block entities:
input layout / lanes:
output ports:
energy bridge / busy constraints:
menu + client provider:
JEI compat:
installer / tier graph:
side-config profile:
generated resources / handwritten exceptions:
tests:
manual verification:
known limits:
```

记录重点是证明 catalog、provider、I/O 和资源四条链都闭合，而不是罗列公共 registry 的逐机改动。
