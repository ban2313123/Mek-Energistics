# 30. 症状排查表

优先沿公共边界排查，不要为单台机器重新实现 AE 生命周期。

| 现象 | 优先检查 |
| --- | --- |
| 机器物品不存在 | catalog requirement、`available()`、provider registration、生成资源和 `registryName()` |
| 放下方块崩溃 | family adapter、optional class gate、mixin plugin、BlockEntity 类型 |
| GUI 打不开 | provider `menuType`、client provider screen、BlockType GUI 和 container 泛型 |
| 样板按钮不出现 | `MeAeMachine`/`MeFactoryAeMachine`、pattern container、catalog/provider 选择 |
| 放入样板后 AE 终端不刷新 | support pattern slot listener、`updatePatterns()`、`ICraftingProvider.requestUpdate` |
| AE 终端看不到机器 | Grid host capability、managed node create/active、AE 频道和 family registration |
| AE 下单失败 | owner `MeInputLayout`、router lane/port、样板归属和 busy 状态 |
| 下单吞原料 | router 是否先完整 simulate，再 execute；是否发生事务回滚 |
| 机器不加工/显示没电 | Mek recipe/cache、AE-backed energy view、unpause callback、输入端口是否真实匹配 |
| 重进世界后不能用 AE 电 | support node lifecycle、new managed node、grid 状态回调和能量容器绑定 |
| 产物留在输出槽 | output ports 是否完整、`AeOutputMode` 类型 flag、AE storage capacity |
| 网络恢复后产物仍不回网 | support ticker 是否有 output backlog、端口对象是否稳定、节点是否唤醒 |
| chemical/fluid 不回网 | `MeOutputPort` key 类型、`AeOutputMode.chemicals()/fluids()`、storage insert |
| 重进世界样板消失 | `AePatternSchema`、`MePatternSlot*`、旧 Inventory 一次性迁移和 pending NBT |
| 自定义终端名丢失 | support save/load、`PatternTerminalName`、64 字符 codec/handler 限制 |
| 扩展 factory 安装器断链 | 完整 sourceBlockId、provider resolver、`CompatFactoryTierGraph` 坐标 |
| EME / MekE 高阶链串错 | catalog provider/family、tierId + machineTypeId、真实来源 namespace |
| JEI 没 catalyst | `OptionalJeiCompat`、catalog family gate、optional JEI provider |
| 资源缺失或覆盖 | `runData`、`CompatMachineResourceProfile`、main/generated 重复路径 |
