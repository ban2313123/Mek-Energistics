# 27. 当前实现索引

新增机器前先从下表寻找最接近的上游 BlockEntity 和 I/O layout；注册实现由 catalog/provider family 决定，AE 行为由共同 support 决定。

| 机器族 | 代表实现 | I/O 关注点 | AE 支撑 |
| --- | --- | --- | --- |
| 单 item | `MeElectricMachineBlockEntity` | item input/output | `MeRecipeMachineAeSupport` |
| item + chemical | `MeMetallurgicInfuserBlockEntity`、`MeAdvancedElectricMachineBlockEntity` | item + chemical | recipe support + layout |
| 双 item | `MeCombinerBlockEntity`、`MeStamperBlockEntity` | 固定主/副 lane | router lanes |
| 副产物 | `MePrecisionSawmillBlockEntity` | 主/secondary output ports | output ticker |
| 三输入反应 | `MePressurizedReactionChamberBlockEntity` | item/fluid/chemical lanes | router lanes |
| chemical + chemical | `MeChemicalInfuserBlockEntity`、`MePigmentMixerBlockEntity` | 可交换 chemical ports | router backtracking |
| 模式切换 | `MeRotaryCondensentratorBlockEntity`、`MeAntiprotonicNucleosynthesizerBlockEntity` | mode-specific ports | owner adapter |
| MekMM/MEKE/EMEK/EMEKE 工厂 | 对应 compat factory BlockEntity | 自动均分、extra/catalyst、输出端口 | `MeFactoryAeSupport` |
| 无 AE crafting 语义工具 | Mek utility BlockEntity | 不声明 pattern I/O | 不进入 ME variant |

所有 factory owner 都优先实现 `MeFactoryIoOwner`；只有真实特殊物理约束才在 owner adapter 中增加 lane 或 busy 逻辑。具体机器不得实现 recipe-specific `pushPattern`。

资源覆盖以 `CompatMachineCatalog` 为准。`hasMeVariant()==false` 的工具机器不会进入 `CompatMachineCatalog.available()`、ME 方块、BlockEntity 或 BlockType 注册；不会再创建额外的无 AE BlockType。
