# 7. 输出回网规则

输出由 owner adapter 显式声明 `MeOutputPort`，不使用运行时隐式登记，也不在具体机器中调用逐槽 `insert*IntoNetwork` helper。`AbstractMeAeSupport.drainPatternOutputs(...)` 扫描这些端口并使用 AE powered insert。

`AeOutputMode` 按资源类型独立控制：

- `items()` 控制物品；
- `chemicals()` 控制 Mekanism chemical；
- `fluids()` 控制流体。

保留所有现有 ordinal 和 NBT key。输出端口只报告实际内容，不能拿样板预期输出过滤副产物。网络存储不足时，只从 Mek 端口扣除本次成功插入的数量，剩余内容继续留在机器内。

共同 support 的 AE ticker 会在输出 backlog、smart-pattern pending 或节点状态变化时继续工作。新增机器要保证 adapter 返回的端口对象在 BlockEntity 生命周期内稳定，并声明所有主输出、副产物、chemical tank 和 fluid tank。

验证至少覆盖：每种输出模式、部分网络容量、网络断开后恢复、区块卸载/读档后重新连接，以及输出槽/tank 满时 Mek recipe 的正常背压。
