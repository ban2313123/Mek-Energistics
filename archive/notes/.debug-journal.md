## Root cause

The overlay controls were anchored at a sixth row (`y=114`) while the 4x9 pattern grid ends at the fourth row, leaving one empty slot row. The shared upgrade hook also treated an already ME-backed factory as a generic `MeAeMachine`, advertising a standalone provider upgrade. On reload, the permanent factory node was restored but its paused Mekanism recipe monitors were not explicitly woken, so node existence alone did not prove network-powered recipe progress.

### Green phase - 2026-08-06T21:45:00+08:00

- Fix: `TileEntityMekanismMeUpgradeLifecycleMixin.java` excludes `MeFactoryAeMachine` from the generic standalone-upgrade branch.
- Fix: `MeFactoryAeSupport.java` wakes `MeFactoryIoOwner.unpauseRecipeMonitors()` at the node restore entry.
