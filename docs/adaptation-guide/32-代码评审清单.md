# 32. 代码评审清单

## catalog 与注册边界

- enum、family、provider、tier/type、sourceBlockId 和 requirement 正确；
- 每个 catalog family 在对应 server provider 有 family adapter；
- 公共 registry/client/JEI 不直接 import optional 实现或调用 `ModList`；
- installer 使用完整 sourceBlockId，等级链使用 `CompatFactoryTierGraph`；
- client provider、JEI compat、mixin accessor 都有可选 gate。

## AE 与机器行为

- BlockEntity 保留上游 recipe/cache、能量和生命周期，不复制 AE 框架；
- owner 声明完整 `MeInputLayout`、lane 约束和 `MeOutputPort`；
- 具体机器不解析 AE key，不按 recipe 类型选择投料路径，不实现 recipe-specific `pushPattern`；
- 所有输入先 simulate，统一 router 执行和回滚；
- smart-pattern 容量计算与实际事务共用 router；
- 所有 output slot、secondary output、chemical tank、fluid tank 都声明，容量不足只扣除成功插入量；
- pattern、priority、terminal name、output mode、pending 数据使用共同 support/NBT 兼容路径。

## 资源与验证

- catalog/profile 资源由 `runData` 生成，特殊模型才手写；
- main/generated 无同路径重复，所有 `hasMeVariant` 机器资源完整；
- `compileJava`、`test`、`build` 通过；
- 客户端验证放置、GUI、样板、单次/批量下单、输出背压、网络恢复、读档和升级；
- 静态检查确认 safe decode 之外没有 `PatternDetailsHelper.decodePattern`，已删除 helper 不存在。
