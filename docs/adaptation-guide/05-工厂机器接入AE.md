# 5. 工厂机器接入 AE 的必做项

工厂实现 `MeFactoryAeMachine`；需要暴露物理 I/O 时同时实现 `MeFactoryIoOwner`，由 `MeFactoryAeSupport` 统一处理样板、输入事务、智能批次、输出 ticker、节点生命周期和 NBT。

工厂 owner 只声明：

- `meInputSlots()`、`meChemicalInputTanks()`、`meFluidInputTanks()`；
- `meOutputSlots()`、`meChemicalOutputTanks()`、`meFluidOutputTanks()`；
- `unpauseRecipeMonitors()`；
- 特殊主槽/副槽/催化剂约束时覆写 `getPatternInputLayout()`。

默认 `MeFactoryIoOwner` 会把 Mekanism 自动均分的物品输入组合成事务端口，并把 chemical/fluid 输入输出转换为统一端口。位置不可交换的输入用 lane 声明。

工厂不实现具体 `pushPattern`，也不读取 Mekanism recipe 类型。`MeFactoryAeMachine` 默认方法将 `KeyCounter[]` 交给 support/router；所有输入先模拟，完整成功后才执行，失败时整体回滚。

能量和 recipe cache 仍使用：

```java
MeFactoryAeSupport.energyContainers(...)
MeFactoryAeSupport.withAeRecipeEnergy(...)
```

输出端口在 owner adapter 中一次性声明。support 根据 `AeOutputMode` 将实际产物 powered-insert 回 AE；网络容量不足时只扣除已成功插入的数量，剩余产物留在 Mek 输出槽/储罐。
