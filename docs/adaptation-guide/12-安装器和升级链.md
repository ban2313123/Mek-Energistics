# 12. 安装器和升级链

`MeInstallerTargetResolver` 先按完整 `sourceBlockId` 查询 `CompatMachineCatalog`。只有上游注册 ID 无法唯一表达工厂等级时，才遍历可用 `CompatMachineProvider.resolveOriginalMachine(state)` 读取 BlockState 属性。

工厂等级、基础机器、下一等级和跨附属链统一由 `CompatFactoryTierGraph` 索引。坐标使用 provider/route、`tierId` 和 `machineTypeId`；不要建立 source path-only 索引、遍历 `MeMekanismMachine.values()` 或复制字符串 tier switch。

新增机器需要确认：

- `sourceBlockId` 与上游完整 namespace/path 一致；
- factory 坐标唯一，不与另一 namespace/type 冲突；
- provider resolver 只处理注册 ID 无法唯一识别的 BlockState；
- `CompatFactoryTierGraphTest` 覆盖 base -> basic、next tier 和跨附属边界；
- upgrade handler 通过 provider 识别 optional installer，并保留 Mek/AE 数据。

`MeMekanismMachine.getBasicFactory/getNextFactory` 是图索引的兼容入口，不应成为第二套等级逻辑。
