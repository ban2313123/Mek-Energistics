# 12. 安装器和升级链

ME 工厂安装器目标解析在 `MeInstallerTargetResolver`，等级关系和反向索引统一由
`CompatFactoryTierGraph` 提供。

它的顺序是：

1. 如果目标已经是 ME 机器，返回 `null`。
2. 按完整 source block ID 或 route + source path 查询目录索引。
3. 读取 Mek `AttributeFactoryType` 和 `AttributeTier`，通过 provider/tier/type 坐标查找目标。
4. 仅在上游注册 ID 无法唯一表达工厂等级时，调用对应 optional compat 的 BlockState 解析器。

因此新增机器要确保：

- `MeMekanismMachine.registryName()` 与原机器 path 能对应。
- 对 factory，目录中的 provider、tier ID 和 machine type ID 必须形成唯一坐标。
- 在 `CompatFactoryTierGraphTest` 中覆盖基础机器、首级工厂、下一等级和跨附属等级边界。
- 对可选模组，compat resolver 能把原机器 block state 映射到 ME machine。
- `ModBlockTypes` 中升级目标正确，尤其 Ultimate -> Extras absolute 的链。

不要在安装器或 compat 类中新增遍历 `MeMekanismMachine.values()` 的查找，也不要重新建立字符串
`switch` 等级链。公开的 `MeMekanismMachine.getBaseMachine/getFactory/getNextFactory` 仅是图索引的兼容入口。
